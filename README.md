# cybersentry-ai
Explainable AI-powered network intrusion detection and anomaly analysis
# Dataset

This project will initially use the UNSW-NB15
network intrusion detection dataset.

## Purpose

The dataset will be used to train and evaluate
machine learning models for network intrusion
detection.

## Data handling

- Raw datasets are not committed to Git.
- Dataset preprocessing will be documented.
- Training and testing splits will be kept separate.
- Evaluation will include precision, recall, F1-score,
  and false-positive rate.
